# Propostes per simplificar l’app

| Prioritat | Què passa actualment | Proposta concreta |
|---|---|---|
| Alta | Canviar «Quin suport vull» genera un exercici nou. L’alumne que s’encalla i demana ajuda perd el problema que intentava resoldre. | Canviar l’ajuda mantenint l’exercici i la resposta escrita. Només «Un altre» hauria de canviar-lo. |
| Alta | En inequacions apareix una finestra de predicció en cada multiplicació o divisió, seguida d’una comparació i, de vegades, una petició d’explicació. | Fer aquesta pregunta inicialment amb un positiu i un negatiu. Després, mostrar un avís breu al costat de l’operació: «Dividim per −2: invertim el signe». |
| Alta | Les reflexions poden desplegar comparació, explicació, inicis de frase, camp de text i botó «Desa». Encara que es puguin tancar, ocupen atenció. | Mostrar primer una frase de retorn i deixar «Vull explicar-ho» com a opció desplegable. |

- **Inici de l’app:** es repeteixen els accessos als mòduls a l’itinerari i a les targetes. Donar protagonisme a les targetes i fer l’itinerari més discret. Canviar «Segueix l’ordre» per «Comença pel 0 o tria el que estàs treballant»: evita suggerir que cal completar-ho tot abans de practicar.
- **Frases descriptives de les targetes de l’inici:** retirar frases com «Quan és solució un nombre? Ho veuràs a la balança.», perquè no aporten coneixement i ocupen un espai innecessari.
