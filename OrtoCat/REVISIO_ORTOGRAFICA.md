# Revisió ortogràfica d'OrtoCat

## Abast actual

Aquesta primera versió treballa cinc blocs de consonantisme:

- B / V
- S / SS / C / Ç / Z / SC
- G / J / TG / TJ
- X / IX / TX / IG
- L / LL / L·L

Els blocs coincideixen amb aspectes habituals dels dictats i materials d'ortografia catalana, però no cobreixen encara tota l'ortografia catalana.

## Blocs pendents per a una versió més completa

Segons l'organització habitual dels aspectes ortogràfics, convindria afegir més endavant:

- A / E
- O / U
- M / N / NY
- B / P, T / D, C / G a final de mot
- R / RR
- H
- Apòstrofs i contraccions
- Accentuació i dièresi
- Guionet

## Millores aplicades en aquesta revisió

- S'ha afegit la s sonora entre vocals: `casa`, `rosa`, `posar`.
- S'ha afegit `SC` en cultismes: `escena`, `piscina`, `ascensor`.
- S'ha matisat la `Ç`: davant `a`, `o`, `u` i també a final de mot.
- S'ha afegit l'imperfet amb `v`: `cantava`, `parlaves`, `miràvem`.
- S'han afegit excepcions i mots memorístics de `G/J`, com `jersei`, `jerarquia` i `Jesús`.
- S'ha corregit `mitjà`, que correspon a `TJ`, no a `TG`.
- S'ha ampliat `X/IX/TX/IG` amb la `x` de `taxi`, `examen`, `text`.
- S'ha reforçat l'ela geminada amb famílies com `col·l-`, `il·l-`, `al·l-` i `mil·l-`.
- S'han afegit pistes en paraules ambigües com `vaca/baca`, `bell/vell`, `beure/veure` i `botar/votar`.

## Criteri pedagògic

No s'han incorporat llistes d'excepcions molt llargues dins les targetes principals. Les normes estan redactades perquè siguin útils per a ESO: clares, practicables i amb exemples freqüents. Les excepcions més rendibles apareixen com a paraules de pràctica o com a notes breus.
