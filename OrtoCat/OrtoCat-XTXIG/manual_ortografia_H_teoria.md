# Manual breu: X / IX / TX / IG

- X inicial: xocolata, xarxa, xemeneia.
- IX darrere de les vocals a, e, o i u: caixa, peix, baixar.
- X també pot sonar com cs/gz: taxi, examen, text.
- TX: cotxe, dutxa, despatx.
- IG final: maig, raig, passeig, desig. Sovint alterna amb g, j, tg o tj en formes de la mateixa família.
